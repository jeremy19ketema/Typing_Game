Typing Game - Web Development Final Project

A fully responsive typing speed test game built with vanilla HTML, CSS, and JavaScript.


🎮 Live Demo

Click The Below Link To Veiw The Project

https://github.com/jeremy19ketema/Typing_Game.git


📋 Features

Real-time typing challenge with 60-second timer

Three difficulty levels (Easy, Medium, Hard)

Game statistics tracking with localStorage

Dark/Light theme toggle

Smooth page transitions

Fully responsive design

Contact form with validation


🚀 How to Run

Clone/download the project files

Open home.html in any modern browser

No installation or build tools required

🛠️ Technologies Used

HTML5 (Semantic elements, forms)

CSS3 (Flexbox, Grid, CSS Variables)

Vanilla JavaScript (Game logic, localStorage, DOM manipulation)

Font Awesome Icons

Google Fonts


📁 Project Structure

home.html - Main game page

about.html - Instructions and features

stat.html - Game statistics and history

contact.html - Contact form page

style.css - All styles combined

script.js - Main game logic

shared.js - Common functionality


🎯 How to Play

Enter your name and select difficulty

Click "Start Game" to begin

Type the highlighted words as quickly and accurately as possible

Track your WPM and accuracy in real-time

View your performance history on the Stats page


📊 Scoring

WPM: Words per minute (correct words only)

Accuracy: Percentage of correctly typed words

Results saved automatically in browser
